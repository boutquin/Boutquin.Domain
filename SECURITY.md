# Security Policy

## Supported Versions

Version 1.0.x is the next release line and will be supported upon publication.
Version 0.7.x remains supported.

| Version | Status |
|---------|--------|
| 1.0.x   | Supported upon publication |
| 0.7.x   | Supported |
| < 0.7   | Unsupported |

## Reporting a Vulnerability

If you discover a security vulnerability in Boutquin.Domain, report it responsibly.

Do not open a public issue for security vulnerabilities.

Please use GitHub Security Advisories to report vulnerabilities privately:
https://github.com/boutquin/Boutquin.Domain/security/advisories/new

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- Acknowledgment: within 48 hours
- Initial assessment: within 7 days
- Fix or mitigation: target within 30 days, depending on severity

### Scope

This policy covers the Boutquin.Domain, Boutquin.AspNetCore, and Boutquin.Validation NuGet packages and their source code. Third-party dependencies (for example the .NET runtime and NuGet dependencies) should be reported to their maintainers.
